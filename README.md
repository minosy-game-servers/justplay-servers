# JustPlay Server Directory

The launcher reads servers.json every five seconds. Add entries with name, address, description, players and maxPlayers. Use an IP or DNS name followed by a port. Only advertise servers you operate. Localhost is always added by the launcher and does not need a directory entry.

Лаунчер читает servers.json раз в пять секунд. Поля сервера: name, address, description, players, maxPlayers. Локальный сервер добавляется автоматически.
